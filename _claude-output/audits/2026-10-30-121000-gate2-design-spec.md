# GATE 2 Design Specification — Landing Page Premium Redesign

## Mission Context
GATE 0 audit complete. GATE 1 decisions validated. This document specifies the visual and structural design for the merged landing page.

---

## Design Principles (from Mission Brief)

1. **Editorial identity** — Typographic hierarchy with Fraunces (editorial) + system sans (UI)
2. **Photographic authenticity** — Real terrain images, no stock, graceful fallbacks
3. **Institutional trust** — Deep green/ivory palette, restrained motion, reduced-motion support
4. **Configuration-driven** — All content from Configuration module, no hardcoded values
5. **Accessibility first** — WCAG AA, keyboard/touch, semantic HTML, ARIA
6. **Responsive by default** — Mobile-first, 320px→1440px+, no horizontal scroll

## 6. Fallback Strategy — Institutional Graphic (Critical)

### When Hero Image Missing/Invalid
**Never**: Broken image, hardcoded local asset, blank space
**Always**: Branded graphic background that maintains readability

### Design: Ivory/Deep Green Geometric Pattern
```css
.institutional-fallback {
  position: absolute; inset: 0;
  background: 
    /* Base: deep green */
    linear-gradient(135deg, var(--color-night) 0%, var(--color-forest) 100%),
    /* Pattern: BAHKANSO hexagon motif */
    url("data:image/svg+xml,<svg>...hexagon grid in var(--color-signal) at 8% opacity...</svg>"),
    /* Accent: signal gradient bar left */
    linear-gradient(90deg, var(--color-signal) 0%, transparent 20%);
  display: flex; align-items: center; justify-content: center;
}
```

### Fallback Content (centered)
```
┌─────────────────────────────────────┐
│  [BAHKANSO Logo or Wordmark]        │
│                                     │
│  Projet agro-pastoral — Côte d'Ivoire  │
│                                     │
│  [CTA: Découvrir nos activités]     │
│  [CTA: Espace de gestion]           │
└─────────────────────────────────────┘
```

### Implementation
```typescript
const HeroBackground = ({ imageUrl, alt, children }) => {
  const [imgError, setImgError] = useState(false);
  const [imgLoading, setImgLoading] = useState(true);
  
  if (!imageUrl || imgError) {
    return <InstitutionalFallback>{children}</InstitutionalFallback>;
  }
  
  return (
    <>
      <img
        src={imageUrl}
        alt={alt}
        onLoad={() => setImgLoading(false)}
        onError={() => setImgError(true)}
        style={{ 
          display: imgError ? 'none' : 'block',
          opacity: imgLoading ? 0 : 1,
          transition: 'opacity var(--duration-500) var(--ease-out)'
        }}
        className="absolute inset-0 w-full h-full object-cover"
      />
      <div className="absolute inset-0" style={{
        background: 'linear-gradient(180deg, rgba(17,26,24,0) 0%, rgba(17,26,24,0.4) 60%, rgba(17,26,24,0.7) 100%)'
      }} />
      {imgLoading && <div className="absolute inset-0 bg-night animate-pulse" aria-hidden="true" />}
    </>
  );
};
```

## Motion & Interaction

### Transitions (from index.css)
```css
--duration-150: 150ms;
--duration-200: 200ms;
--duration-300: 300ms;
--duration-500: 500ms;
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
```

### Reduced Motion (mandatory)
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### Interaction States
| Element | Hover/Focus | Touch Active |
|---------|-------------|--------------|
| Activity card | `translateY(-4px)`, shadow-xl, border-color signal | `translateY(-2px)` |

| CTA primary | bg signal → signal-hover, scale 1.02 | scale 0.98 |
| CTA secondary | border ink, bg surface-raised | bg border-subtle |
| Nav link | underline scaleX(1), color terra | color signal |

## Accessibility Checklist

- [ ] Semantic HTML: `header`, `main`, `section`, `footer`, `nav`, `article`, `ol/li`
- [ ] ARIA: `aria-labelledby` on sections, `aria-label` on nav/landmarks
- [ ] Alt text: `hero.heroAlt` required, decorative images `aria-hidden="true"`
- [ ] Focus visible: All interactive elements have `:focus-visible` styles
- [ ] Color contrast: WCAG AA minimum (4.5:1 text, 3:1 UI)
- [ ] Keyboard: All hover interactions mirrored on `:focus-visible`
- [ ] Reduced motion: Respected globally
- [ ] Touch targets: Minimum 44×44px
- [ ] Language: `lang="fr"` on html
