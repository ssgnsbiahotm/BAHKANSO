## Decisions Summary

### 1. Base Page: FUSION (Merge)
- **Keep from current `/`**: Notre suivi, Notre projet, Contact sections
- **Take from prototype**: Hero immersive, activities presentation, editorial hierarchy, photographic compositions
- **NOT**: Blind replacement — build superior version preserving existing functionality

### 2. Hero Image: REUSE EXISTING CONFIG
- **Use directly**: `hero.heroImage` + `hero.heroAlt` from Configuration
- **NO**: New `hero-cover` key in siteContent
- **NO**: Duplicate Dashboard's media lookup mechanism
- **Reuse**: Existing media resolution services/mechanisms

### 3. Media Mapping: EXISTING SLOTS ONLY

| Slot | Source | Notes |
|------|--------|-------|
| Hero background | `hero.heroImage` + `hero.heroAlt` | Primary |
| Logo | `farm.logo_url` | Already connected |
| Dashboard cover | `siteContent['hero-cover'].mediaId` | Dashboard only |
| Trust badges | `hero.trustBadges` | If populated |
| CTA section | `cta.*` | title, subtitle, primary, secondary |
| Footer content | `footer.*` | description, modules, security, copyright |

**Activities illustrations**: NO new Configuration fields this mission. Use typographic compositions + BAHKANSO-consistent icons.

### 4. Fallback Strategy: INSTITUTIONAL GRAPHIC
- **No hero image configured** → Ivory/deep green graphic background + BAHKANSO-inspired pattern
- **Preserve**: Title/CTA readability
- **Never**: Broken image, hardcoded local photo
- **Handle**: Invalid URLs, load errors gracefully

### 5. Content & Indicators: AUTHENTIC ONLY
- **Remove**: Fake "En cours" stats
- **Show only**: Verifiable, available data
- **Connect**: `hero.trustBadges`, `cta.*`, `footer.*` when populated
- **NO**: Invented certifications, partners, performances

## Technical Implementation Notes

### Data Access Pattern (from Configuration.tsx)
```typescript
// Effective value with draft support:
const getEffectiveValue = (path: string) => 
  path in draftsMap ? draftsMap[path] : currentValues[path];

// Hero fields paths:
const heroImagePath = getDraftPath('contenu', 'hero', 'heroImage');
const heroAltPath = getDraftPath('contenu', 'hero', 'heroAlt');
const heroImage = getEffectiveValue(heroImagePath);
const heroAlt = getEffectiveValue(heroAltPath);
```

### LandingPage Must:
1. Import `useData` for `siteContent`, `media`, `farm`
2. Read `siteContent['hero']?.value?.heroImage` and `heroAlt`
3. Read `siteContent['cta']?.value` for CTA section
4. Read `siteContent['footer']?.value` for Footer
5. Read `siteContent['hero']?.value?.trustBadges` for badges
6. Apply fallback graphic when `heroImage` is null/empty/invalid

### Image Error Handling
```typescript
const [imgError, setImgError] = useState(false);
<img 
  src={heroImage} 
  alt={heroAlt || 'Hero'}
  onError={() => setImgError(true)}
  style={{ display: imgError ? 'none' : 'block' }}
/>
{imgError && <FallbackGraphic />}
```
