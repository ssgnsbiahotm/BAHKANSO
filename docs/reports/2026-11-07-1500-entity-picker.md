## Contexte

Architecture "Danse du Cobra" : Phase A a créé la colonne vertébrale
financial_links. Phase B1 crée un composant <EntityPicker> réutilisable pour
sélectionner une entité métier (fournisseur, parcelle, campagne, animal, etc.)
via un autocomplete, alimenté par les sources de useData().

## Constats

**DataContext exposé :** funders, suppliers, sites, plots, campaigns, animals,
animalLots, projects (aucune source `customers` → retourne [] gracieusement).

**9 types d'entité supportés :** funder, supplier, site, plot, campaign,
animal, animal_lot, project, customer.

**Composant créé :** `src/components/ui/EntityPicker.tsx` (~200 lignes)
- Debounce 150ms, max 50 résultats
- Bouton clear (×), navigation clavier (↓/↑/Enter/Escape/Tab), clic hors zone pour fermer
- Accessibilité : role="combobox" sur l'input, role="listbox" sur la liste,
  role="option" sur chaque item, aria-expanded/aria-controls/aria-autocomplete/
  aria-activedescendant/aria-selected, ids uniques
- Styling cohérent avec FormInput (border-default/danger, focus:ring-accent-primary)
- Gère le cas `customer` non exposé par useData() → []

**Test créé :** `src/components/ui/EntityPicker.test.tsx` (3 tests)
1. Rend le label, l'input et le placeholder
2. La sélection met à jour onChange
3. ArrowDown puis Enter sélectionne le premier item

**Validation technique :**

