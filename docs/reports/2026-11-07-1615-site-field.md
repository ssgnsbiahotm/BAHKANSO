Date : 2026-11-07 16:15

## Contexte

Décision D3 = B+C : SiteField affiche un select readonly si l'utilisateur a un
seul site accessible, un select modifiable s'il en a plusieurs, et force le
choix si le contexte est "Tous les sites".

## Constats

### Composant créé : `src/components/ui/SiteField.tsx` (~100 lignes)

Lit depuis `useSite()` (SiteContext) : `availableSites` (sites), `currentSiteId`, `isGlobalView`.

4 cas :
- **A — 1 site** : input readonly avec le nom, icône `Lock` (lucide)
- **B — Multi + site actif** : `<select>` pré-sélectionné sur currentSiteId
- **C — Multi + Tous** : `<select>` vide avec "— Choisir un site —"
- **D — 0 site** : input disabled + message "Créez un site dans Configuration → Sites"

Auto-sélection (useEffect) :
- `!value && sites.length === 1` → `onChange(sites[0].id)`
- `!value && currentSiteId && sites.length > 1` → `onChange(currentSiteId)`

Style cohérent avec FormInput (border-default/danger, focus:ring-accent-primary).

### Test créé : `src/components/ui/SiteField.test.tsx` (4 tests)
1. Cas A : input readonly avec le nom, pas de `<select>`
2. Cas B : select pré-sélectionné sur currentSiteId
3. Cas C : select vide avec "— Choisir un site —"
4. Cas D : message "Aucun site disponible" (placeholder) + input disabled

### Ajustements de test
- Mock `lucide-react` avec `importOriginal` + icône `Lock` surchargée (cas A rend Lock)
- `Aucun site disponible` est un `placeholder` → `getByPlaceholderText`
